# BENI AI 🤖💙

BENI AI is my personal AI assistant made with Python.

## Features

- 🎤 Voice Input (Whisper)
- 🗣️ Voice Output (Edge TTS)
- 🧠 Memory System
- 🌐 Open Google
- ▶️ Open YouTube
- 📝 Open Notepad
- 🧮 Open Calculator
- 💾 Remember User Information
- 👋 Welcome Back Message

## Run

```bash
py -3.12 main.py
```
