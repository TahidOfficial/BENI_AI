# 🤖 BENI AI

BENI AI is a personal desktop voice assistant built with Python.

## ✨ Features

- 🎤 Voice Mode
- ⌨️ Text Mode
- 🎙️ Voice + Text Mode
- 🇮🇳 Hindi Support
- 🇬🇧 English Support
- 🔀 Hinglish Support
- 🧠 Memory System
- 🌐 Open Google
- ▶️ Open YouTube
- 📝 Open Notepad
- 🧮 Open Calculator
- 🗣️ Natural Voice using Microsoft Edge TTS
- 🎧 Speech Recognition using Whisper
- 👋 Welcome Back Message

## 🐍 Requirements

- Python 3.12 ✅
- Windows 10 / 11

## 📦 Libraries

- openai-whisper
- edge-tts
- sounddevice
- scipy
- torch
- PyAudio
- SpeechRecognition
